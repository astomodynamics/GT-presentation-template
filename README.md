# GT-presentation-template

This repository is a LaTeX Beamer template for the Space Systems Design Laboratory at the Georgia Institute of Technology. The template was derived from <https://github.com/usamamuneeb/uic-beamer-template> and adapted through Overleaf projects.

Feel free to fork and change this template.

## Usage
1. Fork this repository.
2. Open Overleaf and import the project from GitHub.
3. Compile the project. XeLaTeX is recommended, but the template now also falls back cleanly to pdfLaTeX-compatible fonts.
4. Download the PDF if needed.
